# opc-ops

### 一个人接私活的防坑外挂

> **你不是技术不够，你是没有章法。**
>
> 这套东西不教你怎么写代码——它管的是更值钱的那件事：**怎么让每一分钱都收得回来。**

---

## 先看一个真实案例

同一双手，同样的技术，两单生意，两个结局。

**第一单，3000 块。** 做完了，客户说"不好用"，拒付尾款。最后只收到 1500。
那一单亏的不是技术，是"不好用"这三个字——它是个模糊词，客户可以把它定义成任何东西，而你没有任何东西可以反驳。

**第二单，16000 块。** 谈钱之前先做了三件事：收 30% 定金、把三个功能写成三条**可验证**的验收标准、定死 7 天售后边界。
交付时客户**说不出"不好用"**——除非你确实没做到。

一字未改的技术能力，差了一万多块。差在哪？
**差在有没有一套流程，把每次交付都变成"有据可查"而不是"凭感觉"。**

这套 `opc-ops`，就是把那套流程整个装进 AI 里。

---

## 这玩意儿到底有多能打

一个技能包，**干掉接单全流程的 11 个崩溃点**：

| 崩溃点 | 没有它会怎样 | 有了它 |
|---|---|---|
| 客户靠不靠谱 | 靠直觉，接完才后悔 | 3 个必问 + 7 条红线扫描，**当场出结论** |
| 该报多少钱 | 心算，报低了不敢改 | 一键算清每一期绝对金额，**定金低于 30% 直接报警** |
| 合同怎么写 | 网上抄一份，漏掉要命的条款 | 8 项必备条款 + 2 个最容易漏的死角，**逐条勾选** |
| 客户老加需求 | 免费干了一个月 | 需求文档带编号，变更必须书面，**反驳有据** |
| 交付要交什么 | 发个压缩包，然后开始扯皮 | 四件套模板，**每个"改改"都对应一行清单** |
| 他拖着不验收 | 等一个月，时间白搭 | 验收期限写死，**逾期视为通过** |
| 他不付尾款 | 慌了，降价，还是收不回 | 源码卡在尾款后 + 结算话术 + **止损线算给你看** |
| 交付后还找你 | 变成免费 on-call | 7 天边界 + 维护报价区间，**开一个口子就是在烧钱** |

**再加上 8 份填完就能发的模板，和 2 个能直接跑的脚本。**

这不是"看看就好"的教程合集。这是一个**能立刻接管你接单全流程的作战系统**。

## 装完就能这么用

不用背命令，不用记流程。你只要像平时一样说话：

**「有个客户说先做着，做完了再谈钱，这单要不要接？」**
→ 它扫一遍聊天记录，命中红线，直接给结论：婉拒。**顺手把婉拒话术写好给你。**

**「1 万 6 的项目，定金该收多少、怎么分期？」**
→ 三秒出结果：定金 8000 / 中期 4800 / 尾款 3200，每一分钱怎么要、什么时候要，全在这。

**「客户说整体还行，但那个啥你再改改。」**
→ 它把验收清单推给你：**一行一个功能点，逐项打勾**。整体评价是主观的，逐项打勾是可对账的。

**「我在第 60% 被客户叫停了，能收多少？」**
→ 算给你：已完成折价 9600 + 未摊薄成本 2000 − 已收 4800 = **还得要 6800**。连话术都给你拟好了。

**「我想搞一人公司，做什么方向？」**
→ 三个低门槛切入口 + 三个判据。**三条都满足才动手，别同时开三个。**

## 两个脚本，现在就能跑

纯标准库，零依赖，Windows / macOS 通吃。

```bash
# 分期拆分（默认 50/30/20，也可以 30/40/30）
python scripts/deal_calc.py split --total 16000

# 中途叫停怎么结算
python scripts/deal_calc.py settle --total 16000 --progress 60 --cost 2000 --received 4800

# 维护该报多少
python scripts/deal_calc.py maintain --total 16000
```

```bash
# 把客户的聊天记录丢进去，看它有多不靠谱
python scripts/risk_scan.py --file chat.txt
```

它会告诉你：命中了哪几条红线、在哪一行、为什么危险、**这单到底该不该接**。

实测一段"烂客户"对话，四句话全部命中红线，结论直接是"建议婉拒"。
换一段"好客户"对话（预算明确 / 有 deadline / 目标可量化 / 愿意书面确认），结论是"三问齐了，可以报价"。

## 一句大实话

接私活最怕的不是能力不够，是**没有章法**。

有章法，你做的每个决定都有依据。就算亏了，你也能精准定位是哪一个环节漏了。
没有章法，亏了就是亏了，**下次还会在同一个地方再亏一次**。

> SOP 的本质不是约束你，是保护你。

这套东西不会让你突然变强。
但它会让你**从"凭感觉接单"变成"按流程收钱"**——而这个转变，值多少钱，上面那个 3000 和 16000 的对比已经说完了。

## 适合谁

- 接私活、做外包、给人做定制的独立开发者
- 刚起步、还没建立自己流程的自由职业者
- 被拖过尾款、被白嫖过、想搞清楚"到底哪一步做错了"的人
- 想从"卖时间"走向"一人公司"的人

**不适合**：想找现成代码、想抄作业、只想看看不想动手的人。这套东西的价值全在"用"，不在"读"。
